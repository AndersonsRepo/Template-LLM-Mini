# Analysis report

## Phase and evidence
State pre/post, inspected dataset references, and approved summaries used.
The coordinator records the inspected data hash automatically.

## Findings and relevance
Explain how the available evidence relates to the task. Do not infer semantic
suitability from file metadata alone.

## Limitations
State access restrictions, uncertainty, unsupported formats, or missing evidence.

## Next action or user question
Recommend pass only when supported; otherwise explain the mismatch or missing
evidence and supply a specific question for the user. Never include raw secrets.

## Attribution and unknowns
Cite data/ files with available page/row/field/section locators and declared original
sources or lineage. Say source unavailable for missing provenance, and unknown
when an answer cannot be determined. Separate observed facts, inference, and
original synthetic content. Do not invent citations or treat generated prose as
evidence. A metadata declaration is not independent source verification.
