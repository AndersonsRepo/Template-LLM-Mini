# Approved evidence and project ground rules

The owner approved centralized rules in templates/agent_rules.md, propagated to
bootstrap/generated instructions, interview, README, initialization primer, and
roles. External evidence is only sourced from ./data; downloading sources into it
requires explicit approval. No downloader is added. Project code and workflow
records remain readable normally.

Preserve available file/origin/locator/lineage details, or state source unavailable.
Original drafts/code/labeled synthetic content need no source; externally derived
facts inside generated material still do. Never invent answers, citations, or test
results; unknown is correct when evidence cannot determine an answer.

Every feature enhancement needs an approved plan after clarifying material
questions. The small-task exception covers only clear fixes/maintenance adding no
functionality. Update relevant instructions/docs for project paradigm changes.
Keep language concise and prune context while preserving decisions, evidence,
unknowns, approvals, and next actions. Include focused Python provenance tests;
metadata validation must not be described as proof of factual correctness.
