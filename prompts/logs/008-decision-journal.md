# Approved running decision journal

The owner requested one running decision log under logging/. They selected
significant decisions and feature milestones, including rejected alternatives
when they explain a tradeoff, and explicitly approved the implementation plan.

Scope: canonical append-only logging/journal.jsonl, generated logging/journal.md,
structured decision capture/filtering, timestamp/ID/task/rationale/outcome/evidence
fields, automatic configuration/task milestones, superseding entries rather than
rewritten history, shared agent/interview/README/primer updates, and focused tests.

Reference existing prompts/memories/evidence instead of copying them. Exclude raw
data, secrets, routine tool chatter, and deliberation transcripts. Python cannot
guarantee every meaningful decision was submitted or independently verify approval.
The reusable template stays unconfigured; no historical decisions are inferred.
