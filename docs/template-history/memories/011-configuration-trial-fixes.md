# Configuration-trial fixes

Behavior: `workflow.py new DEST` clones the template with a fetch-only `template`
remote, the repo-local identity (when the template has one), and `core.hooksPath`.
`configure` writes a project README (only replacing the template's own), a generated
`.gitignore` block that un-ignores `data.approved_fixtures` (kept in sync by
`update-config`, regenerated by `install-hooks`, enforced by pre-commit), and prints
`workflow.py doctor` (hooks path, git identity, WORKFLOW_AGENT, Claude session root,
template remotes, fixtures; SessionStart repeats its warnings). `configure --assumed`
journals the "Assumed unless you object" list that a bare approval accepts.
`validate-config` lists every structural problem with field paths; add-on errors name
allowed formats and provenance shape. Mutating commands warn when the identity
defaults to `local`.

Task flow: handoffs after the first may omit `--file` (reuse plus `--set`), the final
handoff attaches the latest memory, `add --prompt-text` and `add --follows TASK`
(non-blocking follow-ups listed on `done`). Reviews record `--reviewer` separately
from the recording agent; in independent/cross-agent modes it must differ from the
builder, and the report must cite the current `review_ref` (snapshot + cycle) from
`context --role reviewer`.

Structure: harness tests live in `scripts/tests/`, add-on tests in
`addons/data_analysis/tests/` (pruned with the add-on), `tests/` is for project
tests, and `workflow.py self-test` runs the harness suites. The command reference
moved to `docs/workflow.md`.

Validation: `self-test` passed (117 tests). An end-to-end rerun of the eCRF trial
(new, configure, T001 to done) needed no `git add -f`, listed all structural config
errors in one run, finished T001 with 4 scratch files (first trial: 8), and rejected
a review without `--reviewer`.

Limitations: the reviewer name and approval remain assertions Python cannot
authenticate; `review_ref` proves the report postdates the current build, not who
wrote it. `new` cannot copy an identity the template checkout lacks (`doctor` warns).
Live Claude hook firing in a session started in a project root and Codex hook support
remain unverified.
