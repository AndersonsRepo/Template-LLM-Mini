# Approved flexible planning policy

The owner approved substantial-change plan approval with an exception for small,
clearly understood tasks. Ask before changes when request, scope, or the need for
planning is uncertain. Material scope changes need renewed approval. Explicit
user instructions override the exception; initial configuration needs approval.
Agents cannot approve plans for the user. Read-only work needs no approval.

Scope: bootstrap/generated AGENTS.md, interview, README, initialization primer.
This is an instruction policy, not new Python approval enforcement.
