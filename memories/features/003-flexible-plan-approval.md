# Flexible plan approval

Substantial changes require a scope/change/validation plan and human approval.
Small clear tasks may proceed without a separate plan. Ask before changes if
classification, request, or scope is uncertain. Explicit user requirements take
precedence. Initial configuration and material scope changes require approval.
Agents cannot approve for the user; read-only work needs no approval.

The rule appears in bootstrap/generated instructions, interview, README, and
primer. Record project boundaries in approvals. Python does not verify approval.
